# 发现与搜索接口与行为约定

无远程搜索接口。索引来自唯一组件目录 `@/components/local/ComponentCatalog/data` 和现有业务页面/UniApp 文档路径。关键词匹配标题、描述、标签，分类计数使用实际匹配结果，结果点击导航到真实页面。搜索历史使用既有 `STORAGE_KEYS.SEARCH_HISTORY`，支持异常缓存恢复、清空和最多 10 条存储。route `keyword?` 可预填搜索。

路由关键词在微信小程序的 `onLoad` 边界解码一次：该端运行时直接透传查询参数。H5/App 路由已解析参数，保留原文，不再次解码。中文和 `&`、`/`、`#`、`%` 等字符保持用户原有含义；非法百分号编码保留原串，页面仍可搜索和编辑。匹配和本机历史缓存使用最终还原的关键词，保留原有去空白与去重行为。
