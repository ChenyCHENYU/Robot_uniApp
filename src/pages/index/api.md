# 首页数据来源与接口边界

首页为个人工作台，不展示组件目录、组件/页面计数、依赖技术栈或虚构的业务指标、任务和新闻。不请求 `/dashboard/stats`、`/dashboard/activities` 或新的业务接口。

| 展示内容             | 实际来源                                                                                              | 行为                                                                                       |
| -------------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 日期、问候、当前身份 | 当前设备时间与 `user` Store                                                                           | 每次返回首页更新日期；真实昵称优先，缺省时显示当前登录账号                                 |
| 常用应用             | 项目既有表单模板、数据列表、审批流程、扫一扫页面；与 `src/pages.json` 对齐                            | 进入真实登记页面，不生成示例业务量或待办                                                   |
| 最近搜索             | 搜索页既有 `STORAGE_KEYS.SEARCH_HISTORY` 缓存                                                         | 展示本机最多 3 条有效、去重关键词；返回时重读。空历史不填充默认词；损坏缓存显示空状态      |
| 我的空间             | 已登记的个人中心与设置页面                                                                            | 个人中心使用 `switchTab`，设置使用 `navigateTo`                                            |
| 网络、平台与版本     | `app` Store 网络事件与系统信息 `uniPlatform`（缺省使用 Uni 编译注入的平台）、项目 `package.json` 版本 | 网页平台 `web` 显示为 H5；网络未检测时显示“待检测”，不推断后端健康；不展示依赖版本或技术栈 |
| 头部未读角标         | 共享 `message` Store 的现有 `/message/unread-count` 接口                                              | 由共享头部处理；首页不请求消息列表、不增加消息摘要或统计卡片                               |

`openSearch(keyword?)` 仅导航到既有搜索页，有关键词时去空白并编码为 `keyword` 路由参数；搜索匹配和历史写入沿用搜索页行为。搜索历史属于当前设备缓存，不伪称为跨设备或按账户同步的资料。

业务页面继续沿用各自已有接口。开发环境的接口由现有 Mock 处理，来源明确为演示；生产构建使用已有接口配置。首页无新增后端写操作。
