# 记录详情接口与行为约定

| 方法 | 路径           | 请求          | 响应               |
| ---- | -------------- | ------------- | ------------------ |
| GET  | `/crud/detail` | `id`          | `CrudItem` 或 null |
| PUT  | `/crud/item`   | `id`, `title` | `CrudItem`         |

没有 ID 时保留 `item_001` 入口。编辑直接保存本记录标题，不再误跳人员填报页。复制分享输出本记录真实内容。既有接口不提供附件与审计历史，因此附件为空；时间记录仅展示返回的 createTime/updatedTime，不虚构上传和操作历史。当前查看人来自用户 Store，不标为记录负责人。

下拉刷新由 `C_Layout` 内容 `scroll-view` 的 refresh 事件驱动，不使用外层页面的原生刷新生命周期。
